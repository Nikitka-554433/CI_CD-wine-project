# Wine Quality Prediction — MLOps проект

# Описание
Сервис предсказания качества красного вина на основе физико-химических параметров.

# Структура проекта
- `src/api/` — FastAPI приложение
- `tests/` — тесты API
- `data/` — данные (версионируются через DVC)
- `models/` — сохранённые модели

# Запуск API командой

uvicorn src.api.app:app --reload --port 8000
